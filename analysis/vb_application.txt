scPOST User's Guide VB Interface Reference
Application Class
| [Explanation]
| Application class holds Postprocessor's application and Setting object (Hereinafter, app is used as a sample variable name indicating this class)
[Example of Instance Acquisition]
You can acquire an instance of the Application class in the following methods.
| Method 1
| Create by starting an application with VBS/VBA
Set app = CreateObject("scPOST_Sx64net.Application.2025")
| Method 2
| Acquire from a running application with VBS/VBA
Set app = GetObject(,"scPOST_Sx64net.Application.2025")
| Method 3
| Acquire from the inside of a running application (only POST)
Set app = GetApplication()

Property
ErrorCode
| [Explanation]
| Error code (integer)
ErrorString
| [Explanation]
| Error message (string)
UserControl(BOOL)
| [Explanation]
| A flag to control Postprocessor(True, False)
(Note) If this flag is set to True, Postprocessor does not quit at the end of script.
Visible
| [Explanation]
| A flag to show/hide the main window (True, False)
True : The main window of this application is visible.
False: The main window of this application is invisible.
The default is False. If it is True, this application terminates only when Quit method is called. If it is False, it automatically terminates when this Application class becomes out of scope. This application does not terminate regardless of True/False while the script is "still" status. Thus if the script terminates with "still" status (For example debugging work is terminated),
WriteBackToEnvFile(BOOL)
| [Explanation]
| A flag to overwrite an environment setting file at the termination(True, False)
(Note) If this flag is set to False, an environment setting file is not overwritten at the termination. The default value is True.

CreateDrawWnd
Set drawwindow=app.CreateDrawWnd(ocx)
| [Explanation]
| Creates the draw window
If the draw window is created by this method, Postprocessor calls callback to the draw window management OCX with the following values.
1 : When the loading the FLD file finishes after a FLD file is dropped on the draw window.
2 : When the draw window is picked using a Point object.
3 : When the draw window is picked using a Surface object.
| [Argument]
| (LPDISPATCH)ocx
| :
| DISPATCH of OCX to control the draw window
| [Return Value]
| (LPDISPATCH)drawwindow
| :
| The created draw window class
Refer to: Split Draw Window Function
Sample file: post_point_pick.xls, post_surface_pick.xls
(Note) When the draw window is created by this method, Quit method must be called to terminate the application.
