To use the properties/methods of these classes, "instances" of these classes should be acquired first.
For how to acquire the instance, refer to the example at the beginning of the section of each class. With that instance, use the properties/methods prepared for the applicable class.
In this manual, the variable name in the parentheses is uniformly used for the instance name of each class, however, you can set other variable name without problem.
