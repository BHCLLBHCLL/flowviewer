Compare
retval=fld.Compare( savepath , disp , typ , ope , retMin , retMax )
| [Explanation]
| Execute variable comparison between multiple FLDs using the comparison dialog
| [Argument]
| (BSTR)savepath
| :
| File name to save the comparison result image(numbers of every file added)
|
| (long)disp
| :
| 0 - Horizontal
1 - Vertical
2 - Tiled
3 - Fit to draw window
|
| (long)typ
| :
| 0 - Do not use status file
1 - Specify the status file in the dialog
2 - Make the same status as the active FLD
|
| (long)ope
| :
| 0 - Do not calculate between FLD
1 - Display difference in image
2 - Calculate differences of displayed variables
3 - Calculate differences of all variables
|
| (VARIANT)retMin
| :
| Array consist of minimum values of color bar when calculating difference in image
|
| (VARIANT)retMax
| :
| Array consist of maximum values of color bar when calculating difference in image
| [Return Value]
| (long)retval
| :
| 0 for success, 1 for failure

CSV

SKIP
